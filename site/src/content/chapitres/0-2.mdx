export const LLAMA = (() => {
  // Llama 3 405B : 6 × N × D, et ses matrices de dim lignes et dim colonnes (code de référence de
  // Meta : wq va de dim à têtes × (dim ÷ têtes) = dim nombres).
  const m = modelePublic('llama-3-405b');
  const operations = 6 * m.parametres * m.jetonsOrigine;
  // Ce que Meta annonce pour cet entraînement (article de Llama 3, section 1), rangé avec le modèle
  // dans les données du calculateur.
  const annonce = m.operationsPubliees;
  exiger(annonce !== undefined, 'les données de Llama 3 405B n’ont plus les opérations annoncées par Meta');
  exiger(Math.abs(operations / annonce - 1) < 0.02, '6 × N × D ne tombe plus sur les opérations annoncées par Meta');
  const [mantisseAnnonce, exposantAnnonce] = annonce.toExponential().split('e').map(Number);
  const [mantisse, exposant] = operations.toExponential(2).split('e');
  const chiffres = mantisse.replace('.', '');
  const poidsMatrice = m.dim * m.dim;
  const part = poidsMatrice / PRESETS_FORGE.tres_grand.parametres;
  exiger(part > 0.5 && part < 1, 'une matrice de Llama 3 405B ne fait plus entre la moitié et la totalité de ton IA');
  exiger(m.dim % m.tetes === 0, 'la dimension de Llama 3 405B ne se partage plus entre ses têtes');
  return {
    parametres: formaterQuantite(m.parametres),
    jetons: formaterQuantite(m.jetonsOrigine),
    operations: formaterPuissanceDeDix(operations),
    enChiffres: `${chiffres} suivi de ${Number(exposant) - (chiffres.length - 1)} zéros`,
    annonce: `${nombre(mantisseAnnonce, decimalesUtiles(mantisseAnnonce))}\u202F×\u202F${dixPuissance(exposantAnnonce)}`,
    dim: nombre(m.dim),
    couches: nombre(m.couches),
    poidsMatrice: formaterQuantite(poidsMatrice),
  };
})();

export const TIRAGE = (() => {

export const LOI = (() => {
  // La part de « fer » sur 100 et sur 100 000 tirages (graine de la figure) : elle se rapproche de sa
  // probabilité, alors que l'écart en nombre de tirages grandit.
  const [nom, compte] = EXEMPLE_COMPTES[0];
  let total = 0;
  for (const [, c] of EXEMPLE_COMPTES) total += c;
  const faits = [NOMBRES_DE_TIRAGES[INDICE_TIRAGES_DEPART], NOMBRES_DE_TIRAGES.at(-1)].map((n) => {
    const tire = resultatsDesTirages(n, GRAINE_TIRAGE)[0].compte;
    const attendu = (compte * n) / total;
    exiger(Number.isInteger(attendu), `« ${nom} » n’est pas attendu un nombre entier de fois sur ${n} tirages`);
    return { n, tire, attendu, ecart: Math.abs(tire - attendu) };
  });
  const [peu, beaucoup] = faits;
  exiger(peu.ecart > 0, `sur ${peu.n} tirages, « ${nom} » sort exactement autant de fois qu’attendu`);
  exiger(beaucoup.ecart / beaucoup.n < peu.ecart / peu.n, `la part de « ${nom} » ne se rapproche pas de sa probabilité`);
  // « tout près » : à moins d'un point de pourcentage de la probabilité.
  exiger(beaucoup.ecart / beaucoup.n < 0.01, `sur ${beaucoup.n} tirages, la part de « ${nom} » n’est pas tout près de sa probabilité`);
  exiger(beaucoup.ecart > peu.ecart, `l’écart en nombre de tirages ne grandit pas avec le nombre de tirages`);
  return faits.map(({ n, tire, attendu, ecart }) => ({
    n: nombre(n),
    tire: nombre(tire),
    attendu: nombre(attendu),
    part: pourcent(tire / n, Math.max(0, String(n).length - 3)),
    ecart: nombre(ecart),
  }));
})();

<Etape numero={1} titre="Des nombres en colonne : les vecteurs">

Un vecteur est une liste de nombres, écrite entre parenthèses : {A} en a deux. On le dessine comme une flèche qui part de l'origine, {ecrireNombre(A_DEPART[0])} cases vers la droite et {ecrireNombre(A_DEPART[1])} vers le haut. Dans ton IA, chaque morceau de texte devient un vecteur de {DIM} nombres : impossible à dessiner, mais les calculs sont exactement les mêmes qu'avec deux.

Deux vecteurs s'additionnent case par case : {A} + {B} = {ecrireVecteur(somme(A_DEPART, B_DEPART))}. Ils se multiplient aussi, et donnent alors un seul nombre, le produit scalaire, noté avec un point : on multiplie les cases deux à deux, puis on additionne. {A} · {B} = {SCALAIRE_DEPART}.

<Pari
  id="scalaire"
  question={`Que vaut ${PARI_A} · ${PARI_B} ?`}
  precision="Multiplie les cases deux à deux, puis additionne."
  choix={choixProduitScalaire()}
  acquis="scalaire"
  ouvre="vecteurs"
>

{PARI_A} · {PARI_B} = {SCALAIRE_PARI}. Le produit est nul : ces deux flèches forment un angle droit, elles sont perpendiculaires. Le produit scalaire dit si deux vecteurs vont dans le même sens : positif s'ils pointent du même côté, nul s'ils sont perpendiculaires, négatif s'ils vont en sens contraires. La figure juste en dessous est ouverte : vérifie-le.

</Pari>

Le produit scalaire grandit aussi avec la longueur des flèches. La longueur d'un vecteur, sa norme, est la racine carrée de son produit scalaire avec lui-même : celle de {A} vaut √{CARRE_A}, environ {NORME_A}. Divisé par les deux normes, le produit scalaire ne garde que la direction : c'est le cosinus de l'angle entre les deux flèches, toujours entre −1 et 1.

<Etape numero={3} titre="La pente">

Une IA apprend en réglant ses poids, des nombres qu'elle ajuste pour faire baisser son erreur. Prends un seul poids, x, et une erreur toute simple, qui vaut <span class="formule-en-texte">(x − 3)² + 1</span>. Cette erreur est la plus basse en x = {ecrireNombre(FOND)}, où elle vaut {ecrireNombre(erreur(FOND))} : c'est le fond. Mais l'IA ne voit pas la courbe en entier. Elle ne connaît que sa position, et la pente sous ses pieds.

La pente dit à quelle vitesse l'erreur monte quand x avance vers la droite : c'est la montée de l'erreur sur un tout petit pas, divisée par la longueur de ce pas. Si l'erreur descend, la pente est négative.

<Etape numero={5} titre="La règle de la chaîne">

Une IA n'est pas une seule formule : c'est une longue chaîne d'opérations, chacune appliquée au résultat de la précédente. Pour descendre la pente, il lui faut pourtant la pente de toute la chaîne. La règle de la chaîne la donne, maillon par maillon.

Prends <span class="formule-en-texte">h(x) = (2x + 1)²</span>. Elle enchaîne deux opérations :

- d'abord <span class="formule-en-texte">f(x) = 2x + 1</span>, dont la pente vaut 2 partout ;
- puis <span class="formule-en-texte">g(u) = u²</span>, le carré du résultat u de f, dont la pente vaut 2u.

La règle dit : la pente de h en x, c'est la pente de g en <span class="formule-en-texte">u = f(x)</span>, multipliée par la pente de f. Quand x avance d'un tout petit pas, u avance 2 fois plus ; et quand u avance d'un tout petit pas, h avance 2u fois plus. Les deux effets se multiplient.

En <span class="formule-en-texte">x = {CHAINE.x}</span>, <span class="formule-en-texte">u = 2 × {CHAINE.x} + 1 = {CHAINE.u}</span>, et <span class="formule-en-texte">h = {CHAINE.u}² = {CHAINE.h}</span>. La pente de g en {CHAINE.u} vaut <span class="formule-en-texte">2 × {CHAINE.u} = {CHAINE.penteExterieur}</span>, celle de f vaut {CHAINE.penteInterieur} : la pente de h en {CHAINE.x} vaut <span class="formule-en-texte">{CHAINE.penteExterieur} × {CHAINE.penteInterieur} = {CHAINE.exacte}</span>. Mesurée sans formule, comme à l'étape 3, la pente approchée de Python vaut {CHAINE.approchee} : presque {CHAINE.exacte}.

  <li data-lignes="1-3">`interieur` : f(x) = 2x + 1, l'opération du dedans.</li>
  <li data-lignes="6-8">`exterieur` : g(u) = u², écrit comme une multiplication, u × u.</li>
  <li data-lignes="11-13">`composee` : h(x) = g(f(x)). On calcule f d'abord, puis g sur son résultat.</li>
  <li data-lignes="16-22">`pente_composee`, la règle de la chaîne : la pente de g en u, 2u, fois la pente de f, 2.</li>
  <li data-lignes="25-35">`exemple_chaine` calcule tout en x = 1, et mesure aussi la pente avec `pente_approchee`, la fonction de l'étape 3, pour vérifier la règle.</li>

Une IA enchaîne des centaines d'opérations, mais la règle reste la même : on multiplie les pentes, maillon par maillon. Au chapitre 0.5, elle servira à remonter l'erreur d'un petit réseau, de la sortie jusqu'à chacun de ses poids. Cette remontée s'appelle la rétropropagation ; c'est elle qui donne à ton IA la pente de son erreur pour chacun de ses poids.

<Fragment slot="note">

En maths, la pente d'une fonction f s'écrit souvent avec un prime : f′(x). La règle de la chaîne devient <span class="formule-en-texte">h′(x) = g′(f(x)) × f′(x)</span>.

</Fragment>

</Etape>

<Etape numero={6} titre="Les probabilités">

Au chapitre 0.1, le programme prenait toujours le mot le plus fréquent, et tournait en rond. Un modèle de langage fait autrement : il transforme ses comptes en probabilités, puis tire au sort.

<Etape numero={7} titre="Des scores aux probabilités, et l'erreur">

À l'étape 6, les probabilités venaient de comptes. Un modèle de langage, lui, calcule un score pour chaque mot possible : un nombre quelconque, positif ou négatif, d'autant plus grand que le mot lui semble convenir. Il doit ensuite changer ces scores en probabilités : c'est le rôle de softmax.

Softmax prend l'exponentielle de chaque score, notée exp. Une exponentielle est toujours positive, et grandit avec le score : le plus grand score garde la plus grande part. Softmax divise ensuite chaque exponentielle par leur somme, si bien que les probabilités font 1 ensemble.

Avant l'exponentielle, les scores sont divisés par un réglage, la température. Sous 1, elle creuse les écarts entre les scores, et le meilleur mot sort plus souvent au tirage ; au-dessus de 1, elle les resserre, et le modèle ose des mots moins probables. Voici softmax pour les trois mots de l'étape 6. Leurs scores : {SCORES}.
