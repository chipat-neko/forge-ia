import AtelierTokenizer from '../../components/chapitres/1-3/AtelierTokenizer.svelte';
import DernieresFusions from '../../components/chapitres/1-3/DernieresFusions.svelte';
import EchelleVocabulaire from '../../components/chapitres/1-3/EchelleVocabulaire.svelte';
import MiniJetons from '../../components/chapitres/1-3/MiniJetons.astro';
import PhraseDecoupee from '../../components/chapitres/1-3/PhraseDecoupee.astro';
import { NB_FUSIONS } from '../../components/chapitres/1-3/fusions';
import { choixNombreDeJetons, tokenizer13, visible } from '../../lib/bpe';
import { typographier } from '../../lib/typo';

export const MOT = 'les forgerons';

export const K = 30;

export const RARE = 'reforgeronnes';

export const jetonsMot = tokenizer13.decouper(MOT, K);

export const jetonsRare = tokenizer13.decouper(RARE, NB_FUSIONS);

export const collesDansMot = (() => {
  // Les morceaux de « les forgerons » déjà collés avec K fusions, dans l'ordre
  // où ils ont été appris. Le symbole de la fusion n (à partir de 1) porte le
  // numéro base.length + n - 1 : son rang se lit dans son numéro.
  const base = tokenizer13.base.length;
  const liste = jetonsMot
    .filter((jeton) => jeton.id !== null && jeton.id >= base)
    .sort((x, y) => x.id - y.id)
    .map((jeton) => `« ${visible(jeton.texte)} » (fusion ${jeton.id - base + 1})`);
  const fin = liste.pop();
  return typographier(liste.length > 0 ? `${liste.join(', ')} et ${fin}` : fin);
})();

<Etape numero={1} titre="Pourquoi découper ?">

Un réseau de neurones fait des calculs. Pour qu'il puisse travailler sur « Le forgeron frappe le métal », il faut transformer cette phrase en une suite de nombres, puis savoir refaire le chemin inverse pour afficher sa réponse. L'outil qui fait cette traduction s'appelle un tokenizer, et les morceaux qu'il produit s'appellent des jetons (<span lang="en">tokens</span> en anglais).

<Pari
  id="nombres"
  question="Au bout du compte, que reçoit vraiment le réseau de neurones ?"
  choix={[{ texte: 'Des lettres' }, { texte: 'Des mots' }, { texte: 'Des nombres', juste: true }]}
  acquis="nombres"
>

Le réseau ne voit que des nombres. Le tokenizer transforme le texte en numéros de jetons à l'entrée, et refait le chemin inverse à la sortie.

</Pari>

<Fragment slot="note">

Le mot anglais <span lang="en">token</span> veut dire jeton, comme ceux d'un jeu de société : un petit objet qui en représente un autre.

</Fragment>

</Etape>

<Etape numero={2} titre="Lettres ou mots ?">

Découper lettre par lettre est simple, mais les phrases deviennent très longues, et le modèle doit tout réapprendre à partir de briques minuscules. Découper mot par mot donne des suites courtes, mais le vocabulaire n'a pas de fin : forger, forgeron, forgeronne, reforgé…

La méthode utilisée par presque tous les grands modèles, le BPE (<span lang="en">Byte Pair Encoding</span>, « encodage par paires »), choisit un entre-deux. On part des lettres. On cherche la paire de symboles voisins la plus fréquente dans un grand texte, on la fusionne en un nouveau symbole, et on recommence.

<Fragment slot="note">

Le BPE a été inventé en 1994 pour compresser des fichiers. Il a été repris en 2015 pour la traduction automatique, puis par les modèles de langage.

</Fragment>

</Etape>

<Etape numero={6} titre="Le code">

Le cœur de l'algorithme tient en quelques lignes de Python. Une première fonction compte toutes les paires de symboles voisins :

<CodeExplique fichier="projets/1.3-tokenizer/tokenizer_pedagogique/bpe.py" region="compter">
  <li data-lignes="1">La fonction reçoit les mots du texte : chaque mot, écrit comme une suite de symboles, est associé à son nombre d'apparitions, par exemple `{('f', 'o', 'r', 'g', 'e'): 12, …}`.</li>
  <li data-lignes="3">`Counter` compte les paires pour nous : une paire encore jamais vue part de zéro.</li>
  <li data-lignes="6">`zip(symboles, symboles[1:])` donne chaque paire de voisins : (f, o), (o, r), (r, g)…</li>
  <li data-lignes="4, 7">On ajoute la fréquence du mot : un mot vu 12 fois compte 12 fois.</li>
</CodeExplique>

<Pari
  id="zip"
  question="Si `symboles` vaut `('l', 'e', 's')`, que donne `list(zip(symboles, symboles[1:]))` ?"
  precision="`symboles[1:]` est la même suite sans son premier élément : `('e', 's')`."
  choix={[
    { texte: "`['le', 'es']`" },
    { texte: "`[('l', 'e'), ('e', 's')]`", juste: true },
    { texte: "`[('l', 'e', 's')]`" },
  ]}
  acquis="zip"
>

`zip` avance dans les deux suites en même temps et forme des couples. En décalant la suite d'un cran (`symboles[1:]`), chaque couple est une paire de voisins : (l, e), puis (e, s). Le « s » final n'a pas de voisin à droite : `zip` s'arrête dès que la plus courte des deux suites est épuisée.

</Pari>

Une seconde fonction choisit, dans ce compte, la paire la plus fréquente. C'est elle qui décide de la prochaine fusion :

<CodeExplique fichier="projets/1.3-tokenizer/tokenizer_pedagogique/bpe.py" region="choisir">
  <li data-lignes="1">La fonction reçoit le compte des paires et renvoie une seule paire, la gagnante.</li>
  <li data-lignes="8">`min` renvoie la paire dont la clé est la plus petite. Ici, la clé est un couple : d'abord `-compte[paire]`, puis la paire elle-même.</li>
  <li data-lignes="7-8">Le signe moins retourne l'ordre : une paire vue 12 fois a une clé qui commence par −12, plus petit que le −5 d'une paire vue 5 fois. `min` prend donc la plus fréquente.</li>
  <li data-lignes="4-5, 8">En cas d'égalité, on prend la paire la plus petite dans l'ordre des numéros des caractères (presque l'ordre alphabétique, sauf que « é » passe après « z ») : le résultat est ainsi toujours le même, sur ton PC comme dans cette page.</li>
</CodeExplique>
