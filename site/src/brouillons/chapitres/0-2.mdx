export const TIRAGE = (() => {
  // Les comptes de l'exemple, leurs probabilités, et où chaque mot se range entre 0 et 1.
  const probas = probabilites(EXEMPLE_COMPTES);

  for (const [, c] of EXEMPLE_COMPTES) total += c;

  const bornes = EXEMPLE_COMPTES.map(([nom, c]) => {
    const debut = cumul;
    cumul += c;
    return { nom, de: ecrireReglage(debut / total), a: ecrireReglage(cumul / total) };

  return {
    total: nombre(total),
    // Les trois phrases de l'étape 6, écrites à partir des comptes ; typographier() pose les espaces fines des guillemets.

    bornes: typographier(enumerer(bornes.map((b) => `« ${b.nom} » de ${b.de} à ${b.a}`))),
  };
})();

export const LOI = (() => {
  // La part de « fer » sur 100 et sur 100 000 tirages (graine de la figure) : elle se rapproche de sa
  // probabilité, alors que l'écart en nombre de tirages grandit.
  const [nom, compte] = EXEMPLE_COMPTES[0];
  let total = 0;
  for (const [, c] of EXEMPLE_COMPTES) total += c;
  const faits = [NOMBRES_DE_TIRAGES[INDICE_TIRAGES_DEPART], NOMBRES_DE_TIRAGES.at(-1)].map((n) => {
    const tire = resultatsDesTirages(n, GRAINE_TIRAGE)[0].compte;

    exiger(Number.isInteger(attendu), `« ${nom} » n’est pas attendu un nombre entier de fois sur ${n} tirages`);
    return { n, tire, attendu, ecart: Math.abs(tire - attendu) };
  });
  const [peu, beaucoup] = faits;
  exiger(beaucoup.ecart / beaucoup.n < peu.ecart / peu.n, `la part de « ${nom} » ne se rapproche pas de sa probabilité`);

  return faits.map(({ n, tire, ecart }) => ({
    n: nombre(n),
    part: pourcent(tire / n, Math.max(0, String(n).length - 3)),
    ecart: nombre(ecart),
  }));
})();

<Etape numero={1} titre="Des nombres en colonne : les vecteurs">

Un vecteur est une liste de nombres, écrite entre parenthèses : {A} en a deux. On le dessine comme une flèche qui part de l'origine, {ecrireNombre(A_DEPART[0])} cases vers la droite et {ecrireNombre(A_DEPART[1])} vers le haut. Dans ton IA, chaque morceau de texte devient un vecteur de {DIM} nombres : impossible à dessiner, mais les calculs sont exactement les mêmes qu'avec deux.

Deux vecteurs s'additionnent case par case : {A} + {B} = {ecrireVecteur(somme(A_DEPART, B_DEPART))}. Ils se multiplient aussi, et donnent alors un seul nombre, le produit scalaire, noté avec un point : on multiplie les cases deux à deux, puis on additionne. {A} · {B} = {SCALAIRE_DEPART}.

<Pari
  id="scalaire"
  question={`Que vaut ${PARI_A} · ${PARI_B} ?`}
  precision="Multiplie les cases deux à deux, puis additionne."
  choix={choixProduitScalaire()}
  acquis="scalaire"
  ouvre="vecteurs"
>

{PARI_A} · {PARI_B} = {SCALAIRE_PARI}. Le produit est nul : ces deux flèches forment un angle droit, elles sont perpendiculaires. Le produit scalaire dit si deux vecteurs vont dans le même sens : positif s'ils pointent du même côté, nul s'ils sont perpendiculaires, négatif s'ils vont en sens contraires. La figure juste en dessous est ouverte : vérifie-le.

</Pari>

Le produit scalaire grandit aussi avec la longueur des flèches. La longueur d'un vecteur, sa norme, est la racine carrée de son produit scalaire avec lui-même : celle de {A} vaut √{CARRE_A}, environ {NORME_A}. Divisé par les deux normes, le produit scalaire ne garde que la direction : c'est le cosinus de l'angle entre les deux flèches, toujours entre −1 et 1.

<Etape numero={3} titre="La pente">

Une IA apprend en réglant ses poids, des nombres qu'elle ajuste pour faire baisser son erreur. Prends un seul poids, x, et une erreur toute simple, qui vaut (x − 3)² + 1. Cette erreur est la plus basse en x = {ecrireNombre(FOND)}, où elle vaut {ecrireNombre(erreur(FOND))} : c'est le fond. Mais l'IA ne voit pas la courbe en entier. Elle ne connaît que sa position, et la pente sous ses pieds.

La pente dit à quelle vitesse l'erreur monte quand x avance vers la droite : c'est la montée de l'erreur sur un tout petit pas, divisée par la longueur de ce pas. Si l'erreur descend, la pente est négative.

<Pari
  id="pente"
  question={`En x = ${ecrireNombre(X_DU_PARI_PENTE)}, la pente de l'erreur est-elle négative, nulle ou positive ?`}
  precision={`Le fond est en x = ${ecrireNombre(FOND)}.`}
  choix={choixPente()}
  acquis="pente"
  ouvre="descente"
>

En x = {PENTE_ZERO.x}, on est à gauche du fond : vers la droite, l'erreur descend, et la pente est négative. Pour cette erreur, la pente vaut 2 × (x − 3), soit {PENTE_ZERO.exacte} en x = {PENTE_ZERO.x}. Pour descendre, il faut donc aller du côté opposé au signe de la pente : ici, vers la droite. La figure juste en dessous est ouverte.

</Pari>

La pente se mesure aussi sans formule : on regarde l'erreur un millionième à droite de x et un millionième à gauche, puis on divise l'écart par la distance. En x = {PENTE_ZERO.x}, Python trouve ainsi {PENTE_ZERO.approchee} au lieu de {PENTE_ZERO.exacte} : presque la même chose. C'est utile quand on n'a pas de formule, mais c'est lent et approché ; ton IA calcule ses pentes exactement.

La figure dessine la courbe de l'erreur, le point x, et la droite qui touche la courbe en ce point, la tangente : sa pente est celle de la courbe. Ses boutons font descendre le point, comme l'explique l'étape suivante.

<Etape numero={4} titre="Descendre la pente">

Voici toute la règle : à chaque pas, x ← x − taux × pente(x). La flèche se lit « devient » : la nouvelle position est l'ancienne, moins le taux fois la pente. Une pente négative fait avancer x vers la droite, une pente positive le fait reculer, et le taux règle la longueur du pas.

Au taux {PREMIER_PAS.taux}, depuis x = {PREMIER_PAS.x0}, la pente vaut {PREMIER_PAS.pente}, et x devient {PREMIER_PAS.x0} − {PREMIER_PAS.taux} × ({PREMIER_PAS.pente}) = {PREMIER_PAS.x1}. C'est exactement ce que fait le bouton « Un pas » de la figure, à l'étape 3.

<Etape numero={6} titre="Les probabilités">

Au chapitre 0.1, le programme prenait toujours le mot le plus fréquent, et tournait en rond. Un modèle de langage fait autrement : il transforme ses comptes en probabilités, puis tire au sort.

Prends un petit texte où le mot « le » est suivi {TIRAGE.suivis}. Chaque compte divisé par le total, {TIRAGE.total}, donne une probabilité : {TIRAGE.probas}. Une probabilité va de 0 à 1, et celles de tous les mots possibles font 1 ensemble.

Pour tirer au sort, on range ces probabilités bout à bout entre 0 et 1 : {TIRAGE.bornes}. On choisit ensuite un nombre au hasard entre 0 et 1, et le mot tiré est celui où il tombe.

<CodeExplique fichier="projets/0.2-maths/maths_utiles/tirage.py" region="tirer">
  <li data-lignes="1-7">`tirer` reçoit les probabilités et un nombre `u`, tiré au hasard entre 0 et 1.</li>
  <li data-lignes="8-12">`cumul` additionne les probabilités une à une : dès que `u` passe sous le cumul, il est tombé dans la case de ce mot.</li>
  <li data-lignes="13-15">Les arrondis des nombres à virgule peuvent laisser le cumul un peu sous 1 : un `u` tout au bout prend le dernier mot.</li>
  <li data-lignes="18-34">`tirages` tire `n` fois, et compte combien de fois chaque mot est sorti.</li>
</CodeExplique>

Le hasard d'un ordinateur est un calcul : on part d'un nombre, la graine, et chaque nouveau nombre découle du précédent. La même graine donne toujours la même suite, sur toutes les machines. Ce site refait les tirages du Python dans ton navigateur, et trouve exactement les mêmes comptes.

  <li data-lignes="35-37">`uniforme` le ramène entre 0 et 1, en le divisant par 2^32.</li>
