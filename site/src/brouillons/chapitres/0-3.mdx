<Etape numero={1} titre="Pourquoi une carte graphique">

Entraîner ton IA, c'est surtout multiplier des matrices, comme au chapitre 0.2 : des milliards de produits scalaires, tous construits de la même façon, et indépendants les uns des autres. Le processeur de ce PC a {FILS.processeur} fils de calcul, chacun capable de tout faire, l'un après l'autre. Une carte graphique a des milliers de petits calculateurs, plus simples, qui font la même opération en même temps, avec une mémoire très rapide.

Sur ce PC, la carte est une RTX 5070 Ti, de NVIDIA. Ton IA a été entraînée quelques pas sur elle, puis sur le processeur, pour comparer.

<Etape numero={2} titre="Le pilote, et rien d'autre">

Pour que PyTorch calcule sur ta carte NVIDIA, il faut trois pièces : la carte, son pilote, et une version de PyTorch faite pour elle. Le pilote est le programme qui fait parler le système à la carte. Il s'installe avec la carte, ou depuis le site ou l'application de NVIDIA.

Et CUDA ? C'est la boîte à outils de NVIDIA pour calculer sur ses cartes. Les versions de PyTorch pour la carte embarquent leur propre CUDA : tu n'as pas besoin d'installer le « CUDA Toolkit ». Il ne sert qu'à compiler PyTorch lui-même, ou des extensions écrites pour CUDA. Il ne te faut que le pilote.

Pour voir ton pilote, tape :

<BlocCommande commandes={[NVIDIA_SMI]} />

`nvidia-smi` est livré avec le pilote. En haut, il affiche la version du pilote, et la version de CUDA la plus haute que ce pilote accepte. En dessous : ta carte, sa mémoire, et les programmes qui s'en servent. Si la commande est introuvable, le pilote n'est pas installé.

Le projet de ce chapitre utilise PyTorch {PC.torch}, fait pour CUDA {PC.cuda}. Un pilote de la série {PILOTE_MINIMUM_CUDA_13} ou plus récent accepte toutes les versions {PC.majeure} de CUDA. Sur ce PC, le pilote {PC.pilote} va jusqu'à CUDA {PC.cudaMax} : c'est largement assez.

Reste la carte elle-même. NVIDIA donne à chacune une capacité de calcul, le numéro de sa génération : {PC.capacite} pour la RTX 5070 Ti, {GENERATION.t4} pour la T4. Une version de PyTorch est compilée pour une liste de générations, ses architectures, écrites comme <code>{PC.architecture}</code> pour la capacité {PC.capacite}. Elle reconnaît une carte si la liste a sa génération, le premier nombre, avec un second nombre plus petit ou égal. La liste du projet n'a pas <code>{GENERATION.nom}</code>, mais <code>{GENERATION.sert}</code> sert une RTX 4070, de capacité {GENERATION.capacite}.

<Fragment slot="note">

**Ce qui rend faux d'anciens tutoriels.**

« Installe le CUDA Toolkit » : inutile pour se servir de PyTorch.

<code>{CONDA_INSTALL_PYTORCH}</code> : ce canal s'est arrêté à PyTorch 2.5.

<code>{PIP_INSTALL_TORCH}</code> sous Windows : tu obtiens la version pour le processeur seul (étape 4).

Les adresses en `cu118` ou `cu121` : ces versions de CUDA ne connaissent pas les cartes RTX 50. Il a fallu attendre CUDA 12.8 et PyTorch 2.7. Et PyTorch 2.15 ne publie plus de version pour CUDA 12.

<Etape numero={5} titre="Vérifier">

Le projet contient un script qui regarde ton poste comme le verront les projets suivants : le système, Python, PyTorch, la carte et son pilote, les fils du processeur. Il en tire un diagnostic, dit quoi faire quand quelque chose cloche, puis fait un essai de calcul. Avec une carte NVIDIA, dans le dossier du projet :

La première fois, uv télécharge la version de PyTorch pour la carte : {ROUES.carte}. Sans carte NVIDIA, ou sur un Mac :

<BlocCommande commandes={[VERIFIER_POSTE_CPU]} ou="un terminal, dans le dossier du projet" />

Chaque constat a un niveau : « bon », « attention » si ça marche moins bien que ça pourrait, « problème » s'il faut agir. Ici, le script met au niveau « attention » la carte laissée de côté, et les fils du processeur que PyTorch n'utilise pas. La dernière ligne compte les problèmes ; s'il y en a, le script rend un code d'erreur.

Le diagnostic est une seule fonction, `diagnostiquer`. Elle ne lance rien : elle lit des faits et rend des constats. On peut donc la tester sur les postes d'autres lecteurs, décrits à la main, sans leur ordinateur.

**Colab.** C'est le service de Google qui fait tourner les notebooks du site dans ton navigateur, sans rien installer. Au {COLAB_T4.date}, Python {COLAB.avecCarte.python} et PyTorch {COLAB.avecCarte.torch} y sont déjà installés, avec une carte ; sans carte, c'est PyTorch {COLAB.sansCarte.torch}. Une carte s'y demande par Exécution, puis Modifier le type d'exécution. Dans l'offre gratuite, elle n'est pas garantie : Google ne la nomme pas, et dit que ses cartes changent avec le temps. Ses utilisateurs rapportent le plus souvent une T4, de capacité {GENERATION.t4}. Une session dure au plus {COLAB.heuresMax} heures. **Mac.** Un Mac n'a pas de carte NVIDIA, donc pas de CUDA.
